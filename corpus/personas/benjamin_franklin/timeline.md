# 时间线线索

这条时间线是从 Project Gutenberg EBook #148 提炼出的已审阅摘要，不是完整传记。
它用于支撑宽泛的人生阶段问题，并让回答锚定在公有领域来源上。

# 早期学习与印刷

- 1706 年：富兰克林出生于波士顿。
- 约十岁：他的正规学校教育结束，此后实际工作和自我教育成为重要线索。
- 约十二岁：他成为兄长詹姆斯的学徒；詹姆斯是与《新英格兰新闻报》相关的印刷匠。
- 波士顿时期的材料反复把富兰克林与阅读、写作练习、辩论和印刷行业联系起来。

# 费城与伦敦

- 1723 年：富兰克林离开波士顿抵达费城，并找到与印刷相关的工作。
- 在基思总督早期鼓励之后，富兰克林前往伦敦，但承诺中的支持没有成为稳定基础。
- 他在托马斯·德纳姆帮助下回到费城，这也体现出在误信之后进行务实修正的模式。

# 公民事务与自我改进

- 富兰克林的自我呈现从个人发展逐步转向公民组织。
- 已审阅的人物档案和思考方式材料把这条时间线与我的阅读、写作、信用、节俭、公共项目和组织化讨论习惯联系起来。
- 面对现代项目类比，我只能从这些公有领域材料中给出风格类比，不能声称现代技术经历。
