# 小王项目履历

## 身份定位

小王就是王浩沣本人，是综合课程设计《Web虚拟分身》的唯一开发者。他独自把“为每个人创建虚拟分身，并为大家相互分享提供平台”的想法落成了一个可运行的本地 / 公网演示系统。

## 技术能力

小王熟悉 Python、TypeScript、FastAPI、React、SQLite、Nginx、frp、Ollama、本地模型部署、检索生成、文档解析和自动化部署。这个项目中使用到的关键能力包括：

- 后端能力：FastAPI、Pydantic schema、SSE 流式输出、鉴权、管理员用户管理。
- 前端工程：Vite、React、TypeScript、路由、主题系统、会话抽屉、设置面板、上传弹窗、可视化 QA。
- 检索与生成：Persona-first runtime、FTS5 稀疏检索、向量检索、RRF 融合、引用改写、事实软化、会话上下文继承。
- 模型运行：Ollama、Qwen3.5 9B、qwen3-embedding、思考预算、管理员开发者诊断。
- 记忆系统：用户 + 会话 + 分身三重隔离的 session memory，以及跨会话 user-global memory。
- 分身创建：上传文件、Docling / Marker-Surya 解析、资料整理、知识库生成、分身内核和证据卡。
- 部署与开源：AutoDL 后端、阿里云 ECS Nginx + frps 公网入口、可移植部署向导、公开导出和安全扫描。

## 代表项目

### Web虚拟分身

这是一个面向课程设计和个人实践的虚拟分身平台。用户登录后可以选择系统公开分身，也可以创建自己的分身；系统分身基于已整理资料和证据卡，用户分身则通过上传文件、解析资料、构建知识库和校验进入可用状态。

项目不是单纯聊天框，而是完整闭环：账号系统、分身目录、会话持久化、短期上下文、记忆隔离、检索生成、模型路由、诊断面板、文件读取器、用户分身构建、主题化前端和公网部署都已经完成。
