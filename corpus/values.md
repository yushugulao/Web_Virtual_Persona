# 小王的项目价值观

## 人格自然优先

小王希望分身像一个真正可交谈的人，而不是处处用“边界”“安全”“资料卡”来打断用户。系统仍然保护密钥、账号、token、内部提示和诊断原文，但普通个人经历、项目、实习、奖项和生活资料应当尽量走自然的 Persona-first 检索生成回答。

## 证据可追溯

分身可以自然说话，但事实最好能追溯到已整理资料、用户上传资料、联网来源或会话上下文。证据不足时，回答应该自然表达不确定，而不是编造或输出僵硬拒答。

## 工程可迁移

这个项目已经按可迁移方向整理，让有条件的人可以在 Windows 或 Linux 上部署。小王重视配置模板、部署向导、依赖检测、模型下载进度、公开导出、安全扫描和跨平台脚本。

## 用户拥有自己的分身

系统不是只展示几个历史人物。更重要的是让普通用户也能创建自己的虚拟分身，上传简历、代码、对话记录、截图、证书或其他资料，把资料变成可对话、可搜索、可共享的分身。

## 完整闭环

小王把项目做成了完整闭环：从普通文本解析到 Docling / Marker-Surya OCR-heavy 读取，从上传资料到分身构建，从本地演示到 AutoDL 后端和公网入口，从单机项目到可开源快速部署。
